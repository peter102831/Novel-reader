小說朗讀書籤

在小說的章節頁按一下這個書籤，手機就會用大字顯示正文並開始朗讀，讀完自動接下一章。

第一步：複製代碼

第二步：存成書籤（Android Chrome）

  1. 在 Chrome 打開任一網頁，按右上角⋮，再按☆加入書籤。
  2. 畫面下方會跳出「已加入書籤」，按旁邊的編輯。
  3. 名稱改成朗讀。網址那一格全部刪掉，貼上剛才複製的代碼。
  4. 按左上角的返回箭頭，會自動儲存。

已經裝過舊版？按 ⋮ → 書籤，在「朗讀」右邊按 ⋮ → 編輯，把網址換成新代碼即可。

讓鎖定後也能繼續唸

  1. 打開手機的設定 → 應用程式 → Chrome → 電池，改成不受限制（各品牌名稱略有不同，也可能叫「允許背景活動」）。
  2. 開始朗讀後，下拉通知列應該會看到「小說朗讀」的播放控制，代表背景模式有啟動。
  3. 鎖定螢幕聽聽看。如果幾秒後就停了，代表你的手機不支援這個技巧，請告訴我。
iPhone 的設定方式（給家人朋友參考）
  1. 在 Safari 隨便打開一個網頁，按下方的分享按鈕，選加入書籤。
  2. 名稱改成朗讀，按儲存。
  3. 打開書籤，按編輯，點剛才的「朗讀」。
  4. 把網址那一格清空，貼上剛才複製的代碼，按完成。

第三步：開始聽書

  1. 打開小說的任一章，例如提莫書屋的第 1 章。
  2. 點一下網址列，打朗讀兩個字，點下方出現的那個書籤（星號圖示）。從書籤選單裡點不會有反應，一定要從網址列點。
  3. 畫面會出現一個很大的黃色按鈕「點這裡開始朗讀」，點下去就開始唸了。

朗讀畫面的按鈕

暫停 / 播放：黃色大按鈕。上一段、下一段：跳段落。慢一點、快一點：調語速。字小、字大：調字體。點任一段文字，會從那段開始唸。

聲音是微軟的台灣神經網路語音，按「換聲音」可以在曉臻、曉雨（女聲）和雲哲（男聲）之間切換。雲端語音連不上時，會自動改用手機內建的聲音。語速、字體大小和聲音都會記住，下次不用再調。鎖定畫面和通知列的播放控制也能暫停、跳段落。如果朗讀在背景被停掉，回到畫面時會自動接著唸。

提莫書屋會把大約 150 個常用字藏成韓文字，書籤會自動換回中文。如果網站哪天換了藏字方式，聽到怪字或漏字時告訴我，我再更新。
